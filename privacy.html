Privacy Policy

Last updated: October 5, 2026

This policy describes how The Money Archive Uploader (the "API Client"), the internal publishing tool of the YouTube channel The Money Archive (@MoneyArchiveDocs), handles information.

Who uses the API Client

The API Client is used exclusively by the owner of The Money Archive channel to publish the channel's own content. It is not offered to the public and no other person can sign in to it.

YouTube API Services

The API Client uses YouTube API Services. By using it, the channel owner agrees to be bound by the YouTube Terms of Service. Google's privacy practices are described in the Google Privacy Policy.

What data is accessed and why

With the channel owner's authorization (OAuth scopes youtube.upload and youtube.force-ssl), the API Client only:

  • uploads the channel's own videos and sets their title, description, tags, schedule and privacy status;
  • uploads the custom thumbnail of each video;
  • uploads caption tracks (English and translations) and localized titles and descriptions for those videos;
  • reads the basic information of the authorized channel (its name and ID) to confirm it is uploading to the right channel.

It does not access, collect, store, analyze, sell or share any data about other YouTube users or viewers, does not read comments or private information, and does not access any other channel.

Storage and security

The only credential involved is the channel owner's OAuth refresh token, which is stored encrypted as a secret of a private GitHub repository and used only by the automated publishing workflow. No user data is stored by the API Client. The channel owner can revoke access at any time from Google Account security settings, after which the API Client can no longer access the channel.

Data retention and deletion

The API Client does not store any YouTube API data: it only sends our own videos, thumbnails, captions and metadata to YouTube, and keeps no copy of data obtained from the API. The only stored item is the OAuth refresh token. To delete it, the channel owner (1) revokes access at myaccount.google.com/permissions, which invalidates the token immediately, and (2) deletes the token secret from the GitHub repository. Any temporary files created during an upload run are discarded when the run ends (at most within 24 hours). Requests to delete data can be sent to the contact address below and are completed within 7 days.

Cookies and tracking

This website and the API Client do not use cookies, analytics or tracking technologies.

Changes
